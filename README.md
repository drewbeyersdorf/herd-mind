# herd-mind (working name)
The aggregator: many animals, one movement. The series hub - each harness runs alone, and this repo shows them moving as one herd.
- Animal behavior: herd-level collective motion - local rules, global order, no leader required.
- Fleet mechanism: the index of all harnesses with live status per harness; the place a reader sees the whole fleet behave like one animal.
- First harness: receipt-dog - https://github.com/drewbeyersdorf/receipt-dog
Status: v0.1, public. Working name. Part of the HERDR animal-harness series.
